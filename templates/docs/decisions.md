# Decisions

Every question that needs an answer from a person gets one row, with an ID the spec cites. Answered rows move to Settled. Rows still waiting stay in Open.

**Type.** *Decision* = the team chose. *Action* = only a human can do it. *Information* = a fact we did not have. *Counsel* = an expert view is needed. *Open* = not yet answered.
