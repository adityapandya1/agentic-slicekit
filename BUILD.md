# BUILD — the queue

One slice, one branch, one pull request. A slice is done when a human has merged it.
Status is `Todo`, `PR #n`, or `Done`. This file is regenerated by `slicekit status --write`; edit the slice files, not this table.
Spec: `docs/spec/`. Decisions: `docs/decisions.md`. Slice files: `docs/phases/`.
