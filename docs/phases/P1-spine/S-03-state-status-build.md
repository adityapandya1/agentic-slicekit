### Task 2: State store and transitions

**Files:** Create `src/state/index.js`, `src/state/transitions.js`, `src/cli/state.js`, `test/state.test.js`.

**Interfaces:**
- `STATES = ['todo','tests-red','building','draft-pr','in-review','changes-requested','ci-green','ready','merged','released']`.
- State file: `{slice, state, branch, pr: {number, url, headSha} | null, redCommit, frozenTests: string[], unfrozen: string[], verdicts: [{round, path, blockers: number, independent: boolean}], ci: {sha, status} | null, handoff: object | null, history: [{from, to, at, by, evidence}]}`. `unfrozen` lists frozen tests released by a slice-file amendment (`slicekit state unfreeze <id> <path>`, which also appends to `history`).
- `readSlice(root, id) → state` (default `todo` object when the file is absent but the slice file exists; throws when neither exists); `listSlices(root, cfg) → [{file, state}]`; `writeSlice(root, state)` via `writeText` (atomic).
- `setState(root, cfg, id, to, evidence: object) → state`; evidence keys per transition, checked by `TRANSITIONS[to].check(current, evidence, ctx) → string | null` (null = allowed, string = reason):
  - `tests-red`: `evidence.commit` (sha), `evidence.testExit !== 0`, `evidence.tests` (paths, non-empty) → stores `redCommit`, `frozenTests`.
  - `building`: `redCommit` set; if `cfg.freezeTests`, every `frozenTests` path exists.
  - `draft-pr`: `evidence.testExit === 0`, `evidence.checkExit === 0`, `evidence.pr.title.startsWith('[' + id + ']')` → stores `pr`.
  - `in-review`: `evidence.verdict` with `round` ≥ 1 → pushes to `verdicts`.
  - `changes-requested`: last verdict `blockers > 0`.
  - `ci-green`: last verdict `blockers === 0` and `evidence.ci.status === 'success'` and `evidence.ci.sha === pr.headSha`.
  - `ready`: `cfg.review.independent === 'optional'` or a verdict with `independent && blockers === 0`.
  - `merged`: `evidence.mergedAt`.
  - `released`: `evidence.release` path exists.
  - Any `to` not reachable from `state` (not the next in order, except `in-review → changes-requested → in-review` and `changes-requested → draft-pr` after a fix push) → `"<from> cannot move to <to>"`.
- `TransitionError extends Error { reason }`; CLI prints `refused: <reason>` and exits 1.
- CLI: `slicekit state set <id> <to> [--commit sha] [--test-exit n] [--check-exit n] [--tests a,b] [--pr-number n --pr-title t --pr-url u --pr-sha s] [--verdict path --round n --blockers n [--independent]] [--ci-status s --ci-sha s] [--merged-at iso] [--release path]`; `slicekit state show <id> [--json]`.

- [ ] **Step 1: Failing tests** — the five `state.test.js` cases; `write is atomic` spawns 20 parallel `setState` calls on 20 slices via `Promise.all` and asserts every file parses and no `.tmp-*` remains; `skipping a state is refused` (`todo → building`).
- [ ] **Step 2–5:** FAIL → implement → PASS → commit `feat(state): store and guarded transitions`.
